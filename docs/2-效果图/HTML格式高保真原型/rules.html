💰 算账公式
基础信息
• 一台 = 20 元
• 最低胡牌：6 台（否则诈胡）
• N = 胡牌方桌上子数 + 点炮方桌上子数
点炮胡（单一结算）
胡牌台数 + 3×(N+1) + dealerBonus?
• 非庄胡 + 非庄炮：无 dealerBonus
• 庄家胡 或 庄家被炮：有 dealerBonus
• dealerBonus：连庄第1次+1台、第2次+3台、第3次+5台...
自摸胡（逐人结算）
每个输家 i 单独计算 Nᵢ
• Nᵢ = 胡牌子数 + 输家i桌上子数
• 各输家应付金额可能不同
• 被自摸者桌上子数清零
⚠️ 特殊规则
最后 8 张牌限制
牌墙剩余 ≤8 张时，不能吃、不能碰、不能碰杠，只能摸杠。
诈胡罚
向每家支付 300 元。如庄家被诈胡，连庄部分照算（防恶意诈胡）。
连庄机制
上庄默认 +1 子(+3台)，连庄追加奇数序列。首次坐庄的 +3 来自 base zi（zi初始化为1），不属于 dealerBonus。
九筒/九万特殊加成
自摸九筒/九万 = 10台，明杠 = 10台，暗杠 = 15台。与普通台数叠加时有特殊计算规则。
