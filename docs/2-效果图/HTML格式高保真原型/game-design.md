# 游戏桌面 — 设计思路

> **对应原型**: `game.html`
> **版本**: v2.0（方案A：中央公共牌河）
> **最后更新**: 2026-09-13
> **状态**: 已确认方向，待视觉评审

---

## 一、设计目标

1. **沉浸式横屏体验** — 4 人麻将桌面，玩家固定在南位（下方）
2. **读牌优先** — 四家弃牌集中中央公共牌河，信息一目了然
3. **操作直觉化** — 选牌 → 确认出牌两步防误触；吃碰杠胡按需弹浮层
4. **信息透明** — 台数徽章常驻、点击展开明细；状态栏左上角常驻

---

## 二、关键设计决策（v2.0 已与用户确认）

| 决策 | 结论 | 说明 |
|------|------|------|
| 弃牌展示 | **集中式公共牌河**（方案A） | 四家弃牌按方位集中到中央区，替代 v1 的四角分散式 |
| 出牌交互 | **两步确认** | 选中手牌（上移+金边）→ 点击「出牌」圆钮；未选牌时按钮置灰 |
| 台数预览 | **徽章收起 + 点击展开** | 平时显示「💡 N台」胶囊，点击展开明细浮层，点击外部收起 |
| 设备基准 | **844×390 横屏** | iPhone 12/13/14/15 系 6.1" 逻辑分辨率，即适配下限 |
| 对手手牌 | **牌侧俯视素材** | 顶部 80° 俯视角素材（`res/tiles/tile_edge_top.png`），西/东家竖排、北家横排，18 张仅占 ~280px 高度 |
| 吃碰杠胡 | **按需浮层** | 平时隐藏，可操作时从手牌上方弹出，含倒计时条 |
| 明牌位置 | **贴各家手牌区** | 各家明牌放在手牌与中央牌河之间；吃/碰 -3、杠 -4 后该家牌侧条数相应减少 |
| 明牌标签 | **四家微型文字标签** | 每组明牌下方 9px 小字「吃/碰/明杠/暗杠」，新手零门槛（已确认） |
| 暗杠摆法 | **按视角区分**（已确认） | **对手暗杠**：4 张全扣牌背，看不到牌面；**自己暗杠**：两端扣+中间两张亮出，仅自己可见杠了什么 |
| 来源方向标记 | **不体现** | 不横放牌标记来源家，全部正向摆放，视觉简洁（已确认） |
| 牌河容量 | **极端场景验证** | 打到剩 4 张（144-68手牌-8花-4余）人均弃牌 16~18：北/南区 23列×2行=46 容量，西/东区 12列×2行=24 容量，全部横排换行、贴各方位 |
| 剩余牌告警 | **≤8 张变红** | 状态栏剩余牌数红色警示（对应规则：最后8张禁止吃/碰/明杠） |
| 屏幕方向 | 强制横屏 | 竖屏时显示横屏提示遮罩 |

## 五、交互流程

### 5.1 出牌流程（两步确认）
```
摸牌 → 手牌区加入新牌
  → 点击选中(上移+金边) → [出牌]按钮亮起
  → 点击[出牌] → 牌飞入中央牌河南区并高亮 → 下一家
  (再次点击已选中的牌 = 取消选中，按钮回灰)
```

### 5.2 吃碰杠胡流程
```
他人打出牌 → 系统检测可操作动作
  → 操作浮层弹出(提示谁打了什么牌 + 倒计时条)
  → 点动作按钮执行 / 点"过"跳过 / 超时自动过
```

### 5.3 台数查看
```
点 [💡N台] 徽章 → 浮层展开明细 → 点徽章或外部区域收起
```

## 六、v1 → v2 已解决问题对照

| v1 问题 | v2 解法 |
|---------|---------|
| 底部一行挤 5 组元素 | 南家拆两行：上行信息(花牌/明牌/徽章)，下行操作(手牌/出牌钮) |
