v4 实现方式

  • 独立裁切: 每张牌从 2754×1482 参考素材中用 sips 精确像素裁切为独立 PNG
  • <img> 标签: 不再使用 CSS 精灵图 background-position，彻底避免坐标偏差问题
  • 可访问性: 每张牌有 title / data-suit / data-rank 属性
  • 预览区复用: preview-hand / preview-meld / preview-discard 三种尺寸 class
  • 注意: 行2(红筒)和行4(红条)已裁切但未在当前页面展示（AC麻将标准只用蓝筒+绿条；红色版本可用于特殊变体）
