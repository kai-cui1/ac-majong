## 1. 产品与玩法概述

### 1.1 产品定位 ✅

- **形态**：微信小游戏，**真人联机对战**的麻将游戏。
- **对局模式**：**房间制**——房主创建房间 → 其他玩家加入 → 人齐开始 → 按规则打牌、算台数、结算积分 → 进入下一局。
- **计分**：**游戏内虚拟积分**（不对应真实货币）。
- **服务端权威**：胡牌判定、台数计算、积分结算全部由**后端**计算，客户端仅做展示与输入，以防作弊。

### 1.2 与标准麻将的关键差异 ✅

| 维度 | 标准麻将 | 本规则（A&C） |
|---|---|---|
| 胡牌张数 | 14 张（4 副 + 1 对） | **17 张（5 副 + 1 对）** |
| 用牌总数 | 136 / 144 | **144（含 8 张花）** |
| 胡牌门槛 | 满足牌型即可 | **必须 ≥ 6 台，否则「诈胡」受罚** |
| 计分方式 | 番 / 倍 | **台数（可叠加累加）** |

> **17 张 / 5 副** 是全篇基石，已由多处交叉验证：小平「除 1 对外其它 5 副皆顺」= 5×3+2 = 17；八对半 = 8×2+1 = 17；十三幺 = 13 张 + 1 对 + 1 副 = 17；风一色/将一色明写「任意 17 张」。

### 1.3 明确不做的范围 ✅

- **砍掉**原始规则中的「积分发布 / 月度排名 / 赛季 / 晚宴颁奖 / 冠亚季军奖杯」整块。
- 不做账号段位排行榜、不做匹配系统（仅房间制）。
- 房间内积分**按局累计**，房间解散即清零。

## 3. 台数计算总纲：必然包含原则【核心】

> ✅ **已确认，并已写入长期记忆。这是整个台数引擎的最高准则，所有番种组合都必须遵循。**

### 3.1 原则陈述

> **两个番种能否相加，取决于二者是否存在「必然包含关系」：**
> - 若牌型 **A 必然包含 B**（只要出现 A，就一定同时出现 B）→ **只计较大番 A，不再重复计 B**。
> - 若 **A 与 B 无必然包含关系**（二者可各自独立出现）→ **台数相加**。

### 3.2 判定方法（工程实现口径）

对一副胡牌，先枚举所有**成立的番种集合**，再对集合内**任意两项**做包含关系判定：凡「被必然包含」的小番从求和中剔除，仅保留不被其它番必然包含的项，最后求和。

### 3.3 实例

| 组合 | 是否叠加 | 结果 | 原因 |
|---|---|---|---|
| 八只花(40) + 见花×8 | ❌ 不叠 | **40** | 八只花**必然包含**见花 |
| 大三元(30) + 见字×3 | ❌ 不叠 | **30** | 大三元**必然包含**见字（中发白三刻） |
| 小三元(15) + 见字×2 | ❌ 不叠 | **15** | 小三元**必然包含**见字（两刻） |
| 将一色(40) + 碰碰胡(15) | ✅ 可叠 | 视牌型 | 将一色**不必然是**碰碰胡（可走八对半对子结构），无必然包含 |
| 风一色(60) + 碰碰胡(15) | ✅ 可叠 | 视牌型 | 同上 |

> ⚠️ **推论待办**：规格书阶段需据此原则，产出一张完整的 **《番种两两包含/互斥矩阵》**，覆盖全部 ~50 个番种，作为引擎去重的依据。

## 4. 胡牌牌型结构

### 4.1 基本型 ✅

**5 副 + 1 对 = 17 张**。其中「副」= 顺子 / 刻子 / 杠。

### 4.2 特殊型

- **八对半**：17 张 = **8 对 + 1 单** 或 **7 对 + 1 刻**（两种均可，N1）。听牌型：手上 8 对、胡任一第 3 张（8 面听）→ 追加 **1独（1台）**；手上 6 对+1 刻+1 单、单钓胡 → 追加 **独独（2台）**。
- **十三幺**：东南西北中发白 + 条/筒/万 各 1、9（共 13 种各一），其中**有且仅有一种成对**，再加**任意一副牌** = 17 张。
- **风一色**：由「东南西北中发白」中任意 **17 张**组成。
- **将一色**：由条/筒/万中的 **2、5、8** 任意组成 **17 张**。

> 💡 **关键交互（✅已确认）**：将一色 / 风一色 **可以走「八对半」的对子结构**，此时**不是**碰碰胡；只有当其为「5 刻 + 1 对」结构时才算碰碰胡。故这两类与碰碰胡**相互独立、满足即叠加**。

### 4.3 副 / 对 / 坎 / 杠 定义

- **顺子**：同门连续三张（如 123、567）。
- **刻子**：三张相同。**碰**出的为明刻；**自己摸到**的三张相同为 **1 坎（暗刻）**。
- **杠**：四张相同。**明杠**（碰后加杠 / 直杠）；**暗杠**（自己摸到四张）。
- **对（将）**：两张相同，作胡牌的将牌。

## 6. 番种与术语精确定义

### 6.1 花 / 字 / 坎 / 杠 📄✅

- **见花 / 无花**：每摸到 1 只花 = 1 台（2 只 = 2 台，以此类推）；**没有摸到花也 = 1 台**。
- **见字 / 无字**：**三张相同的字**（东南西北中发白）= 1 台，无论碰或自摸；**一对字 = 0 台**；**一个字都没有 = 无字 = 1 台**。
- **无花无字**（3 台）：既没有花、也没有字的胡牌。
- **八只花**（40 台）：摸满 8 只花即呈现胡牌选项（**可选胡**，D-26）；胡牌台数 = 40 + 其他成立番（D-27）。
- **坎**：自己摸到的三张相同牌 = 1 坎（即暗刻）。

### 6.2 听牌型：独独 / 1独 / 对碰

> 这三项描述「胡牌时的听牌形状」，是引擎最难精确实现的部分。

- **独独（2 台）** 📄✅：只能胡**唯一一张**牌——单钓将、卡张（坎窿）、**边张**（如 12 胡 3、89 胡 7）均计入。
- **1独（1 台）** ✅：**能胡超过 1 张牌（多面听、非单钓），且胡的这张牌是手上已有的那张**。
  - 验证例（均一致）：`2345678` 胡 2/5/8（手上有 2、5、8）；`5678` 胡 5/8；`5567` 胡 5 算（有 5）、胡 8 不算（无 8）；`23445` 胡 3 算（有 3）、胡 6 不算（无 6）。
- **对碰（1 台）** 📄✅：双碰听——手上两个对子，胡任一张使其成刻（即「对倒」）。
  - ✅ **已确认**：对碰本身也满足 1独 的定义（多面听 + 胡手上有的牌）。按**必然包含原则**，对碰 ⊇ 1独，**只算 1 台**（不叠成 2 台）；与特例 1「九筒九万对碰自摸」只计对碰 1 台一致。

### 6.3 平：小平 / 大平

- **小平（2 台）** 📄：**无字、无坎（暗刻）、至少 1 只花**，除 1 对将外，其它 5 副**皆为顺子**（如 123、567）。
- **大平（8 台）** 📄：满足小平的其它条件，但**没有花**。

### 6.4 风类 + 东风字

- **小三风（8 台）** 📄：**两个风刻 + 一对风**（如 东东东、南南南、北北）。
- **大三风（15 台）** 📄：**三个风刻**（如 南南南、北北北、西西西）。
- **小四喜（40 台）** 📄：**三个风刻 + 一对风**（如 东东东、南南南、北北北、西西）。
- **大四喜（60 台）** 📄：**四个风刻**。
- **东风字（非庄家 2 台 / 庄家 3 台）** 📄：手上有**三个东**（成字）时计；**一对东不算**。台数随庄家身份变化。

> 💡 大四喜必然包含大三风、见字×4 → 按包含原则不重复计（详见规格书矩阵）。

### 6.5 元类：小三元 / 大三元

- **小三元（15 台）** 📄：中发白中**两个成刻 + 一个成对**（如 发发发、中中中、白白）。
- **大三元（30 台）** 📄：中发白**三个都成刻**。

### 6.6 一色与缺门

- **混一色（15 台）** 📄：条/筒/万中**只有其中一门** + **字**。
- **清一色（40 台）** 📄：**只有条/筒/万中的一门**（无字）。
- **缺一门（4 台）** 📄：只包含条/筒/万中**任意两门**。
- **将一色（40 台）** 📄：由条/筒/万中的 **2、5、8** 任意组成 **17 张**。
- **风一色（60 台）** 📄：由 **东南西北中发白** 中任意 **17 张** 组成。

### 6.7 连番类：姊妹 / 相逢 / 一条龙

- **三姊妹（15 台）** 📄：**同一门**中**三个相连的刻子**（如 666777888）。
- **四姊妹（30 台）** 📄：同一门中**四个相连的刻子**（类推）。
- **三相逢（8 台）** 📄：条/筒/万**三门各一组相同序列的顺子**（如 678条 + 678筒 + 678万）。
- **一条龙（8 台）** 📄：**同一门 1–9** 各一张（123456789，共三副顺）。

### 6.8 特殊大牌

- **十三幺（40 台）** 📄：见 [4.2 特殊型](#42-特殊型)。
- **全求人（8 台）** 📄：其它 5 副牌**都通过吃/碰亮在台面上**，只剩 1 张单钓的暗牌胡。**此单钓不计独独**；若**暗杠则不算**全求人，**明杠则算**。
- **八只花（40 台）** 📄：只要**抓满 8 只花**即算胡牌（必然包含见花，不再另计见花台）。

### 6.9 九筒 / 九万系列（高价值牌，仅筒、万，无条）

- **胡九筒 / 胡九万（5 台）** 📄：**胡的那张牌**是九筒 / 九万。
- **3九筒 / 3九万（5 台）** 📄：手上有**三个九筒 / 九万**（碰或自摸都算）。
- **明杠九筒 / 九万（10 台）**、**自摸九筒 / 九万（10 台）**、**暗杠九筒 / 九万（15 台）** 📄。
- **叠加**：「胡九筒」与「3九筒」可叠加（见特例 2：碰九筒胡 = 胡九筒5 + 3九筒5 + 对碰1 = 11 台）。

### 6.10 坎 / 杠 与补牌胡

- **明杠（1 台/个）**、**暗杠（2 台/个，即 1 暗杠）** 📄。
- **暗坎（暗刻）计数**：2 暗坎 = 2 台、三暗坎 = 8 台、四暗坎 = 15 台、**五暗坎 = 50 台**（✅以表为准）。
  - **点炮口径（2026-09-18 用户确认）**：**点炮胡时，由胡牌张凑成的第三张刻子不计入暗坎**（该刻视为明刻参与暗坎计数）；**自摸胡则计入**；胡牌张作将/另作他用时其余刻子不受影响。
- **杠开胡（5 台）** 📄：开杠后**补摸的那张牌**胡（杠上开花）。
- **花开胡（5 台）** ✅：**摸花后补摸的那张牌**胡。
- **抢杠胡（4 台）** 📄：别人**加杠（碰后补杠）**的那张牌被你胡。
- **海底捞（8 台）** ✅：**自摸牌墙最后一张可摸的牌**（即第 140 张，因最后 4 张为死牌）。

### 6.11 门清 / 自摸 与「门清一摸三/二/一」

- **基础台**：门清（1 台）、自摸（1 台）各自独立。
- **门清自摸 = 门清一摸三（3 台）** 📄：门清 + 自摸的常规合计**按 3 台**（非 1+1=2）。
- **门清一摸二（2 台）** 📄：**门清摸九筒/九万胡**、或**八对半自摸** → 降为 2 台。
- **门清一摸一（1 台）** 📄：**八对半 + 九筒/九万自摸** → 降为 1 台。
- ⚠️ 三档为**覆盖式特例**（满足特定条件时覆盖常规 3 台），触发条件以第 8 节特例为准。

### 6.12 最小胡（一台变八台，8 台）✅

**定义**：算下来**恰好只有 1 台**的那个「唯一最小牌型」，被特殊提升为 **8 台**（1 变 8），使最小牌型也能满足 ≥6 台门槛、别人点炮即可 8 台胡掉。

**同时满足以下 4 个条件**（缺一不可）：

1. **手上恰好有一对「字」或「风」**——此时既非「见字」（需三张）也非「无字」（完全无字），字部分 = **0 台**。
2. **花为「无花」或「恰好 1 花」**——两者都 = 1 台；≥2 花则超过 1 台，不满足。
3. **不能是门清**（须有吃/碰亮明，否则门清 +1）。
4. **点炮胡、不能自摸**（自摸 +1）。

→ 此时总台数 = 1（仅来自花），按「1 变 8」计为 **8 台**。

> ✅ **门槛机制（已确认）**：除「最小胡（1→8）」这一特例外，凡算下来为 **2~5 台**的牌都因 <6 台 → **视为诈胡、不能胡**。客户端需据此在「能否点胡」上给出明确提示，避免玩家误操作被判诈胡。

## 7. 台数计算示例（原文 + 校正）

> 📄 以下算例来自原文，用于演示「叠加」原理。❗ **数值以第 5 节台数表为准**（例 7/8/10 的混一色、碰碰胡、五暗坎原文取值与表不符，已校正）；最终算分还需叠加**必然包含去重**。

| # | 原文算式 | 原文结果 | ✅ 校正后 |
|---|---|---|---|
| 1 | 1花(1)+无字(1)+小平(2)+独独(2) | 6 | **6** |
| 2 | 1花(1)+无字(1)+小平(2)+1独(1)+自摸(1) | 6 | **6** |

## 8. 计算特例（原文）

> 📄 以下为覆盖常规叠加的特殊算例，引擎需优先处理。

1. **九筒/九万对碰自摸** = **16 台** = 自摸九筒(10) + 3九筒(5) + 对碰(1)。
2. **碰九筒/九万胡牌** = **11 台** = 胡九筒(5) + 3九筒(5) + 对碰(1)。
3. **门清摸九筒/九万胡牌**：算**门清一摸二（2 台）**，而非门清一摸三（3 台）。
4. **八对半自摸**：也是**门清一摸二（2 台）**；若**八对半九筒/九万自摸** → **门清一摸一（1 台）**。
5. **八对半胡牌中若有 4 个九筒或九万作为 2 对** → **另外加 10 台**。
6. **倒数第二张摸花或摸杠胡牌** = **12 台** = 海底捞(8) + 杠开(5) − 1 台。

## 9. 结算与算账

> ❗ **合规映射**：原文所有「元」在本项目一律为**虚拟积分**（1 台 = 20 积分）；不可兑换现金。

### 9.1 子与连庄 📄✅

- **上庄**（成为庄家）：默认加 **1 个子**，代表**额外加 3 台**。
- **连庄**：每次连庄默认再加 1 子，并**视连庄次数按 1、3、5、7、9… 追加台数**。
- 这些台数是**胡牌后额外追加算账的台数**，与胡牌台数相加 = **最终算账台数**。
- **子清零**：若自己点炮或被自摸，则自己桌上的子数**清零**（拿下收起）。

### 9.2 最终台数结算公式 📄（2026-09-17 修订，D-25）

**积分与台数 1:1**（废除 1 台=20 倍率）。每家应付的**最终台数**：

| 加成项 | 规则 |
|---|---|
| 子 | 胡牌方每子 +3 台；**付方自身的子 likewise 每子 +3 台**（非庄家遗留子同样计入，胡牌/点炮都算） |
| 连庄 | 庄家**胡牌或点炮**时，连庄 n 追加 2n−1 台（1/3/5/7/9…） |

即：`最终台数(付方) = 胡牌台数 + 3×(胡方子 + 付方子) + (庄家涉及 ? 2n−1 : 0)`；**加成显性计入台数明细与合计**（结算页展示「子 ×Z」「连庄 n」行）；6 台起胡门槛仍只按基础番种台数判定。

> 自摸时三家各付、点炮时点炮方付；付方积分 = 其最终台数（1:1）。子清零规则见 9.1。

### 9.3 诈胡 📄

- 诈胡方需向**其它每一家支付 300**（虚拟积分，即 15 台×20）作为机会损失补偿。
- **特别注释**：~~若庄家被拉诈胡，则「拉的部分」与「连庄的部分」照算~~ → ✅ **本游戏不支持「拉」玩法**（N5），此条不实现。

### 9.4 结算细则 ✅

- **谁付谁**：**点炮胡 = 仅点炮方付**给胡牌方；**自摸 = 其余三家各付**给胡牌方（自摸时对每家分别计算，`N = 胡牌方子数 + 该家子数`）。
- **连庄轮转**：**庄家胡 → 连庄**（庄不变、连庄数 +1、庄家再 +1 子）；**闲家胡 → 换庄**（下家上庄、连庄数归 0、新庄 +1 子）。
- **连庄加分映射**：连庄次数 `n → 追加 2n−1 台`（即 1 / 3 / 5 / 7 / 9…）。
- **子获得 / 清零**：上庄 +1 子、每次连庄再 +1 子；**自己点炮或被自摸时，自己桌上子数清零**。
- **一炮多响**：一张弃牌被多家同时胡 → **都成立**，点炮方分别按各家最终台数赔付。
- **荒庄**：摸到最后 4 张死牌前无人胡 → **本局不计分、无人得失，庄家连庄**。
