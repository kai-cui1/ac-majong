## 1. 模块目标

让玩家**随时查规则、按需调设置**：内置一份与业务基线一致的《游戏规则》说明，降低 A&C 定制规则的上手门槛；设置页提供音效/静音、退出房间等基础控制。规则页是**只读内容展示**，设置页是**本地偏好 + 房间操作**。

## 3. 交互与页面

### 3.1 规则说明页（P9）

- **入口**：大厅「规则说明」、牌桌顶部菜单「规则」。
- **形态**：全屏页或弹层（牌桌内用弹层，关闭即回到对局，不中断）。
- **内容**：按业务基线分节展示；文字为主，可配牌型示意（复用牌面素材）。
- **一致性**：内容须与 [`../0-业务规则/AC麻将游戏规则说明书.md`](../0-业务规则/AC麻将游戏规则说明书.md) 及台数计算规格保持一致，规则变更时同步更新（文档先行）。

### 3.2 设置（P10）

- **形态**：弹层（牌桌菜单「设置」或大厅入口）。
- **项**：音效/静音开关、退出房间、返回登录、版本号与协议入口。
- **本地偏好**：静音等偏好持久化到本地（`sys.localStorage`），下次进入沿用。

## 4. 依赖与边界

- **依赖**：业务基线《游戏规则说明书》（规则内容源）；前端基座（`uiModal`/`UiKit` 页面构建）；表现层（音效受静音开关控制）；房间系统/断线托管（退出房间的后续处理）；登录鉴权（返回登录断连）。
- **边界（不在本模块）**：规则本身「是什么」以业务基线为准，本页只做**展示**；音效资源与播放归 [07-表现动画音效.md](./07-表现动画音效.md)；退出后的座位保留/托管归 [06-断线重连与托管.md](./06-断线重连与托管.md)。
