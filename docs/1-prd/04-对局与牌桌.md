## 1. 模块目标

在牌桌上忠实还原 A&C 规则的一整局：服务端权威发牌与行牌，玩家摸打、吃碰杠胡，局末按台数结算并进入下一局。**算分透明、防作弊、流程顺畅**。

## 4. 牌桌页（P6）信息架构与关键元素

> 仅定义信息架构（做什么）；高保真视觉见 [`../2-效果图/HTML格式高保真原型/game.html`](../2-效果图/HTML格式高保真原型/game.html)，还原对齐为 BL-003。

- **底部（自己）**：手牌（点选打牌，两步确认；**刚摸的牌抽出抬高**显示；点选**按位置**选中，一对牌仅抬被点的那张；38×48@y-156、抬升 8/6、选中金边，方案A重排）、操作按钮（吃 / 碰 / 杠 / 胡 / 过；**自己回合补杠/暗杠**按 `kong_added`/`kong_concealed` 出按钮，多解弹选择器）、理牌、**听牌台数预览**徽章（💡 N台 + 展开明细）。
- **中央**：牌河（各家有序弃牌；西/东家弃牌**6 列横排、置于墙列与风盘之间**（墙列内侧，空间语义=手牌→牌墙→牌河），行内**自边缘向中心**填——西自左→右、东自右→左，2026-09-18 用户确认）、剩余牌墙数、庄家标识、各家子数。
- **四家**：头像 / 昵称 / 积分 / 在线状态 / 托管标识、各家亮明的吃 / 碰 / 杠；**吃副被吃牌居中竖放+右上小圆形角标标记**（FR-对局-17，四家可见）。
- **开局仪式遮罩（BL-017，FR-对局-18/19）**：四家骰子区（骰面+点数+重掷徽章）、点数榜、A 选座高亮、定庄/摸牌位骰横幅；仪式结束自动进入第 1 局发牌。
- **四边牌墙排（BL-017，FR-对局-20）**：physical 模式每排 18 组牌背栈实时递减（栈两态：满栈实心/半栈半透；已摸栈留缺口、跳区常色牌背）、开牌缺口高亮；**南墙排 y-62/北墙排 y+116 独立带（向桌中心），与明牌行（y-104 贴手牌）彻底分带**（方案A重排，2026-09-18 用户确认）；开牌点图例瞬态提示（新局显示一次、5s 自隐、浮层出现即隐）；random 模式仅剩余张数（现状）。
- **顶部**：房间号、局数进度（x/N）、菜单（规则 / 设置 / 退出）。
- **反馈**：操作倒计时进度条（FR-对局-13）、轮到自己的高亮、可胡 / 可碰提示。
- **防透视**：客户端只拿到自己的暗牌，他家仅暗牌张数（见服务端网关与房间技术方案）。

## 6. 局末与续局

- 本局结束（有人胡 `settled` 或荒庄 `exhaustive`）→ 弹结算浮层（台数明细 + 积分变动）。
- **续局由客户端驱动**：玩家查看结算后点「下一局 ▶」推进；服务端设**相位守卫**（仅本局已结束时受理，防重复推进）。
- 打满局数上限（`maxRounds`）→ 进入「对局结束」，展示总战绩、可「再来一局」（见 [05-结算与积分战绩.md](./05-结算与积分战绩.md)）。
