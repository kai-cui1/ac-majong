## 1. 模块目标

一键进入、身份唯一、合规前置：玩家无需账号密码，微信授权即登录；首次进入完成协议与健康提示确认后方可开局。

## 2. 功能需求（FR）

| 编号 | 需求 | 优先级 | 状态 |
|---|---|---|---|
| FR-登录-01 | 微信授权登录：`wx.login` 获取 code → 后端换 openid 作唯一身份；获取昵称/头像用于展示 | P0 | 🟡 mock 已通；真实 `code2Session` → M-K |
| FR-登录-02 | 无账号密码体系；重进自动恢复登录态 | P0 | 🟡 本地 mock 身份持久化（localStorage）；会话恢复对局 → M-I |
| FR-登录-03 | 合规：首次进入展示《用户协议》《隐私政策》与健康游戏提示，需勾选同意方可登录 | P0 | ✅ |

## 3. 交互与页面（P1）

- 品牌 Logo + 标题「AC 麻将俱乐部」+ 副标题。
- 「微信一键登录」按钮：**未勾选协议时置灰不可点**，勾选后变亮。
- 协议勾选行：《用户协议》《隐私政策》+「已年满 18 周岁」确认。
- 健康游戏提示：虚拟积分不可兑换/提现、适度游戏益脑。
- 版本号。
- **登录状态提示**：登录中…；失败时提示「连接失败，请确认服务端已启动」并恢复按钮。

## 4. 关键流程

```
勾选协议 → 按钮可用 → 点「微信一键登录」
 → 客户端取本地身份(mock) + 上报昵称/头像 → 连接服务端并 auth
 → 服务端校验身份 → users 落库(upsert，刷新 lastLoginAt) + 建会话(Redis，TTL)
 → authOk 回传 { userId, profile } → 进入大厅（用户条显示真实昵称 / ID）
```

## 5. 数据与身份

- **身份（谁）**：openid 为唯一身份，由服务端校验（权威）；客户端不可伪造。
- **资料（展示）**：昵称 / 头像由客户端上报（`UserProfile`）。
- **落库**：每次登录 upsert `users`（openid / nickname / avatarUrl / lastLoginAt）。
- **会话**：登录后建立会话（token → openid，TTL），用于鉴权与后续重连恢复（对局恢复 → M-I）。
- 技术细节见 [`../3-技术文档/AC麻将-登录鉴权.md`](../3-技术文档/AC麻将-登录鉴权.md)。

## 6. 合规

- 虚拟积分不可兑现、无赌博暗示（NFR-04，见 [00-产品总览.md](./00-产品总览.md)）。
- 首次进入协议勾选 + 健康提示；未成年人保护（如需）。

## 7. 依赖与边界

- **依赖**：业务基线身份/合规决策；技术方案《登录鉴权》；网络层（连接/传输）。
- **边界（不在本模块）**：真实微信 `wx.login → code2Session`、服务端签发 session token → M-K；断线重连恢复登录态与对局 → M-I（BL-007）。
