## 1. 模块目标

以**房间**为对局容器：房主组局、好友入局、满员开局、打满散场。房间号 + 微信分享实现「一键入局、无需匹配」；服务端权威管理座位、开始条件与生命周期。**房间 = 一个完整结算周期（BL-016）**：周期内各玩家在本房的累计积分持久保留（跨退出/重进、跨服务重启），房间关闭时积分定格、玩家据此**线下相互结算**；房间号**全局唯一、永不复用**。

## 3. 交互与页面

### 3.1 房间等待页（P5）

- **4 个座位**：空位显示「等待加入…」；已入座显示头像 / 昵称 / 在线状态；**房主位**加标识；**Bot 座位**显示「机器人」标识。
- **房间号**：显著展示 6 位房号 + `复制` / `微信分享` 按钮。
- **局数上限**：显示本房设定（x 局 / 不限）。
- **玩法参数（BL-017，FR-房间-10）**：显示本房牌墙模式（物理牌墙/随机发牌）与摸牌位骰开关；建房弹层内由房主勾选。
- **添加机器人**（仅房主，FR-房间-08）：为空位放入 Bot（1~3 个），可在「等真人」与「补 Bot 开局」间自由组合；真人加入时优先占空位，房主可移除多余 Bot。
- **开始按钮**：仅房主可见可点；座位**满 4 人**（真人 + Bot）才可点（未满置灰并提示「等待更多玩家或添加机器人」）。
- **退出**：离开房间返回大厅。

### 3.2 分享卡片

- 微信分享携带房间号，好友点击直接进入该房等待页（免手输）。真实分享 API → M-K。

## 4. 关键流程

```
房主：创建(选局数上限) → 生成房号(全局唯一·永不复用) → 等待页 → 分享邀真人 / 放入 1~3 Bot → 满 4 人(真人+Bot) → 点「开始」→ 对局
玩家：输房号/点分享 → 校验(存在·未满·未开始；已关闭拒绝) → 入座等待页 → 房主开始后进入对局
成员重进：输房号 → 房间在内存→直接恢复座位/积分；不在内存(服务重启)→DB 事件溯源重建后恢复
对局循环 N 局(每局末积分入账本) → 达局数上限 / 房主解散(「不限」时仅此) → 散场总战绩 → 房间关闭(积分定格·线下结算)
```

> 服务端房间状态机（`waiting`/`playing`/`finished`）、座位管理、开始守卫、防透视裁剪的实现见 [`../3-技术文档/AC麻将-服务端网关与房间.md`](../3-技术文档/AC麻将-服务端网关与房间.md)。

## 5. 数据与持久化

- **房间落库**：`rooms`（房号 / 房主 / 局数上限 / 初始·**成员积分账本 `member_scores`**·最终积分 / 状态）+ `room_member_events`（create/join/leave/ready 进出流水）。DDL 见 [`../3-技术文档/AC麻将-数据持久化与事件溯源.md`](../3-技术文档/AC麻将-数据持久化与事件溯源.md) §4。
- **积分账本（BL-016）**：每局末将各家累计积分写入 `rooms.member_scores`；服务重启后由「最新一局快照 + 动作日志（含 Redis 未落盘缓冲）」事件溯源重建房间与积分（FR-房间-09）。
- **玩法参数（BL-017）**：`rooms.settings` JSON（`wallMode`/`breakDice`），建房落库、开局仪式与发牌路径据此分支；选位骰结果落 `rooms.seating` JSON（事件溯源可复现）。
- **局数上限表示**：`4/8/16` 存具体值；**`不限`** 以约定值（如 `0`/`null`）表示，续局时不做上限判定（技术实现见 [`../3-技术文档/AC麻将-服务端网关与房间.md`](../3-技术文档/AC麻将-服务端网关与房间.md)）。
- **接线进度**：登录落库（M-B）、房间创建落库（M-C）、成员进出落库（M-D）、对局事件溯源（M-E）、结算台数明细（M-F）、散场 `closeRoom(final_score)`（M-G）均已接线（见持久化技术方案 §7 BL-013）。
- **积分**：随房间生命周期存在，**跨退出/重进保留**；房间关闭时定格（`final_score`）作为线下结算依据，不做跨房账户（D-03/D-32，详见 [05-结算与积分战绩.md](./05-结算与积分战绩.md)）。

## 6. 依赖与边界

- **依赖**：大厅入口（创建/加入来源）；服务端网关与房间（房间状态机）；持久化（房间落库）；网络层（`create`/`join`/`start`/`leave` 指令与 `RoomView`）。
- **边界（不在本模块）**：局内对局归 [04-对局与牌桌.md](./04-对局与牌桌.md)；散场战绩展示归 [05-结算与积分战绩.md](./05-结算与积分战绩.md)；中途掉线/退房托管归 [06-断线重连与托管.md](./06-断线重连与托管.md)；微信分享 API → M-K。
