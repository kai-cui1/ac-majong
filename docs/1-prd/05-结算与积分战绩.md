## 1. 模块目标

**算分透明**是产品核心价值：每局结束清晰展示「哪些番种、各多少台、各家积分怎么变」；房间内积分按局累计、实时可见，**跨退出/重进保留直至房间关闭（BL-016）**；散场给出本房总战绩，积分定格作为玩家**线下相互结算**的依据。**无跨房账户、无赛季排行**——积分只服务于本房间的这一场。

## 3. 积分规则

- **换算**：1 台 = 1 积分（2026-09-17 简化，D-25）；子/连庄加成显性计入：**按付方逐家**以子注列明（底台 + 胡方子每只+3 + 付方自身子每只+3 + 庄家涉及时连庄 2n−1），替代旧「含子/连庄 +N」笼统小字（2026-09-18 v2）。
- **支付方向**：点炮 = 点炮方付；自摸 = 三家各付；含子 / 连庄公式（D-17/18/19）。
- **荒庄**：不计分、无人得失、庄家连庄（D-21）。
- **诈胡**：<6 台的「胡」被拒并罚分（每家付固定罚分，D-15；实现见对局流程引擎）。
- **累计范围**：积分仅在**本房间内**按局累计，**跨退出/重进保留**（BL-016）；房间关闭时定格，作为玩家**线下相互结算**依据（D-03：不落账户、不跨房）。

## 4. 交互与页面

### 4.1 局末结算弹窗（P7）

- **本局结果**：胡牌方 / 荒庄标识、点炮方（如有）；**角色个性化横幅**（2026-09-18 v2）：胡方=「🎉 本局你为胡方 · 共收 +N」（金）、被胡付方=「💸 本局你点炮/对方自摸 · 付 N 分（构成见子注）」（红）、无关方=「本局与你无关 · 积分不变」（灰）；胡方为自己时标题改「🎉 你胡 X台！」。
- **子/庄明细子注**（2026-09-18 v2）：积分变动列每行附 9px 子注——胡方=「胡 X 台 · 收点炮方/自摸收 N 家」；付方=「[庄家·]底 X·胡方子 K(+3K)·自身子 J(+3J)·连庄 M(+2M−1)」（零项省略）；左列合计下注「子/连庄加成按付方逐家计入（右列子注）」；「我累计」含本局变动。
- **台数明细**：番种构成逐条列出（番种名 + 台数），合计台数（对应 FR-积分-05）。
- **积分变动**：各家本局 ±变动 + 当前累计，正负分色。
- **续局入口**：`下一局 ▶`（客户端驱动，服务端相位守卫；见 [04-对局与牌桌.md](./04-对局与牌桌.md) §6）；达局数上限则显示「对局结束」→ 散场战绩。
- **解散入口**：房主在结果页可见「解散牌局」（不限局数且非末局）；点击先弹**二次确认框**（解散牌局？/ 确认解散 / 取消），确认后才真正解散，防误点；确认框阻隔下层输入。
- **各家手牌区**：结算浮层内以 2×2 牌面行展示四家终局手牌（摊牌），不依赖浮层背后的牌桌即可看清（对应 FR-对局-15）。

### 4.2 散场总战绩页（P8）

- **总积分**：各家最终积分排名（本房间内）。
- **线下结算提示（FR-积分-06，BL-016）**：页面底部提示「房间已关闭、积分定格，请按积分差线下相互结算」，替代原「积分清零」表述。
- **局数回顾**：打了 N 局、每局简要（可选，回看依赖 BL-012 回放）。
- **再来一局**：房内「再来一局」= 离开旧房 + 重新建房（服务端补 Bot 并开局，Q4 已实现房内路径）。
- **返回大厅**：房间关闭、积分定格（`final_score` 落库，线下结算依据）。

## 5. 数据与持久化

- **每局落库**：`games`（局号 / 庄家 / seed / 结束类型 / 结果 JSON）+ `game_actions`（动作日志）+ `game_initial_states`（初始牌墙/起手），支持**事件溯源还原**每一局（见 [`../3-技术文档/AC麻将-数据持久化与事件溯源.md`](../3-技术文档/AC麻将-数据持久化与事件溯源.md)）。
- **散场落库**：`rooms.final_score`（各家最终积分定格，线下结算依据）+ `status=closed`；局中积分账本 `rooms.member_scores`（每局末更新，BL-016）。
- **接线进度**：对局落库（M-E）/ 结算台数明细（M-F：`win` 事件透传 `detail` 入 `games.result`）/ 散场 `closeRoom(final_score)`+`status=closed`（M-G）均已接线，见持久化技术方案 §7。

## 6. 依赖与边界

- **依赖**：台数计算规格书（算台规则）；对局流程引擎（结算/连庄/荒庄/诈胡）；持久化（战绩落库与还原）；房间系统（散场时机）。
- **边界（不在本模块）**：局内行牌与胡牌判定归 [04-对局与牌桌.md](./04-对局与牌桌.md)；结算动画/音效归 [07-表现动画音效.md](./07-表现动画音效.md)；跨房账户/赛季/排行**不做**（D-03，非目标见 [00-产品总览.md](./00-产品总览.md) §2.2）。
